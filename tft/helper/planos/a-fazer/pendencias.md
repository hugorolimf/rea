# Pendências (o que ficou para depois)

Lista viva do que os agentes entregaram como "fica para depois", "fora deste passo" ou "só com o jogo aberto". Cada item
diz de onde veio, o que falta e o executor previsto. Quando um item virar trabalho, ele sai daqui e vai para o plano
próprio (ou é marcado como feito). Atualizada a cada agente que termina.

Última atualização: 2026-10-11 (inclui todos os agentes desta rodada).
