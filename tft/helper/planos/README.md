# Planos do TFT helper

Índice de todos os planos, separados por estado. **Ao mudar o estado de um plano, mova o arquivo para a pasta certa e
atualize a linha dele aqui.** Esta página é o ponto de entrada estável: prefira citar `planos/README.md` a citar o caminho de
um plano, que muda quando o estado muda.

- `a-fazer/`: aprovado ou pedido, ainda não começou.
- `em-andamento/`: um agente está executando agora.
- `feitos/`: concluído; fica como registro de decisões e medições.

O documento de arquitetura (`../ARQUITETURA.md`) fica na raiz porque o código e os agentes o citam por esse caminho.
O plano de migração para o núcleo único (M0–M10) está dentro dele.
